# 倒倒乐

倒水排序小游戏原型：把同色的水倒到一起，每个瓶子只装一种颜色就过关。

- 在线试玩：https://jarliao.github.io/daodaole/

## 玩法

- **倒水**：点一个瓶子拿起来，再点另一个瓶子倒进去；也可以直接把瓶子拖过去，没对准也会倒进最近的瓶子。
- **规则**：只能倒在同色上面或空瓶里；顶上连着的同色会一起倒，倒不下的留在原瓶。
- **问号**：部分关卡下面的颜色是问号，上面倒走后才翻开。
- **自动收尾**：只剩单色瓶时，自动把同色并到一起，几瓶同时倒，连着凑满会出「连成 ×N」。
- **救场**：走进死路时提示「退回 N 步」（算好退到最近一个还能解的地方），也可以加一个空瓶。
- **冰冻瓶**（第 18 关起）：结了冰的瓶子不能倒出也不能倒入，头顶数字是还要凑满几瓶，凑够了冰就化开。
- **小瓶**（第 34 关起）：只装 2 格，可以临时放颜色，过关时要倒空。
- **困难关**：挑战模式里标「难」的关，开场有提示、背景变红，多给 3 次撤销、1 次提示、1 个空瓶。
- **收藏**：首页「★ 收藏」。按累计星星解锁背景（夜空、晚霞、森林、深海、糖果、鎏金）和液体质感（经典、果冻、荧光、星光、珠光），星星不会花掉。
- **晒成绩**：过关后生成一张成绩卡，能调系统分享就直接分享；微信里长按图片保存或转发。
- **每日挑战**：首页的日历卡片。按本机日期出题，同一天所有人玩同一局；平日 10 色，周末 11 色带问号；按挑战规则计时，记录当天最佳用时和连续打卡天数。

## 两种模式

| | 爽玩 | 挑战 |
|---|---|---|
| 操作 | 点哪倒哪：点一下自动挑最好的地方倒（会避开倒完就无解的走法） | 点选或拖动 |
| 关卡 | 颜色少两种，颜色多时多给一个空瓶，没有问号 | 颜色逐渐加到 12 种，有问号关 |
| 道具 | 撤销、提示不限次数，每关可加 2 个空瓶 | 撤销 5 次、提示 3 次、加瓶 1 次，用完每次计时加 20 秒 |
| 死路提醒 | 走进死路马上提醒 | 只在没有可倒的时候提醒，提示道具会告诉你 |
| 成绩 | 按步数给星，不计时 | 按步数给星，记录每关最佳用时（留给以后的排行榜） |

## 关卡设计

- 第 1 关教学：手把手倒两步，第三步演示自动收尾；第 2 关巩固；第 3 关开始有挑战；之后按「紧—松—中」循环，颜色逐渐变多，每 4 关一个问号关。
- 每关离线生成 24 个候选，先用求解器确认有解并算出标准步数，再让一个「偏爱倒在同色上、走进死路会撤销」的模拟玩家玩 12 次，按要撤销的次数排难度，按关卡定位取对应百分位的那一个。
- 爽玩模式单独挑一套，只取最顺的。
- 困难关是「紧」关里不带问号的那些（第 7 关，以及第 11 关起每 3 关一个），离线选关时取最难的 85% 分位，模拟玩家要撤销的次数明显高于前后两关。
- 新玩法每 15 关左右加一种：冰冻瓶第 18 关入门，之后每 5 关一次（第 30 关起冻两瓶，分别要凑满 1 瓶、2 瓶）；小瓶第 34 关入门，之后每 5 关一次，两个 2 格小瓶顶替一个空瓶。入门关取偏容易的那一个。规则写进了求解器，所以仍然每关有解。
- 每日挑战不查表：用日期当种子现场摆局，取第一个求解器能解的，同一天结果在任何设备上都一样。

## 目录

```
src/game.html       游戏源码（单文件，规则引擎在 ENGINE-START/END 之间）
index.html          由 scripts/build.mjs 生成的独立网页（GitHub Pages）
scripts/levels.mjs  离线挑关卡种子并写回 src/game.html
scripts/check.mjs   回归检查：标准解逐步回放；随机乱倒后一定能退回到有解的局面；未来 120 天的每日挑战都有解且同一天一致
scripts/build.mjs   生成 index.html
```

```bash
node scripts/levels.mjs 60   # 改了生成规则或难度后重新挑种子（可加 challenge 或 casual 只挑一种）
node scripts/check.mjs 60    # 回归检查
node scripts/build.mjs       # 生成 index.html
```

画面用 Canvas 实时绘制（倾斜时液面保持水平、按面积计算水量），音效由 WebAudio 合成，无外部素材。
